<p class="emp-about-body">Interactive teaching tools built in the lab. Every demo runs entirely in
the browser — nothing to install, no data to upload, no account to create — and each one is
written for classroom use, instrument training and self-study. The physics is computed live, so
every parameter can be explored and its effect is visible at once in the picture and in the
numbers.</p>

<p class="emp-about-body">Each tool below is embedded as a live, interactive frame; open it in a
new window if you prefer a full-size view. The cards give a short description of what each demo
covers and link to the full write-up with the underlying physics.</p>
